# QuickPay Prank

A harmless, mobile-first prank webpage designed to work on Android and iPhone.

## Run locally
Open `index.html` in a browser.

## Publish
Upload the three files (`index.html`, `style.css`, `script.js`) to a GitHub repository and enable GitHub Pages.

Then put the GitHub Pages URL behind the "Release Funds" button/link in your email.

No payment information is collected and no real transaction occurs.
